ANCILLARY MATERIAL FOR GROUNDING WITHOUT CORRECTIVE CONTROL

online-resource-1.pdf
  Six-page methodological supplement specifying the component tests and
  fake-data stress tests discussed in the article.

gelman_fake_data_workflow.R
  Reproducible R script used to generate the constructed data, summaries,
  and paired-difference figure in Online Resource 1.

gelman_fake_data_*.csv and gelman_fake_data_metadata.txt
  Constructed replication-level results, paired comparisons, calibration
  summaries, aggregate summaries, and run metadata generated by the script.

The constructed data audit the proposed comparison; they are not empirical
observations about deployed language-model systems.
